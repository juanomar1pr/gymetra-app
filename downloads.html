Mac .dmg

  1. Click Download for Mac and save Gymetra-macOS-1.0.0.dmg (or whatever version the filename shows).
  2. Open the DMG (double-click).
  3. Drag Gymetra into the Applications folder.
  4. Open Gymetra from Applications or Launchpad.
Download for Mac

If macOS shows a security warning the first time, go to System Settings → Privacy & Security to allow it to open, or Control-click → Open on the app.
